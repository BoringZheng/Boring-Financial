\section{自动化测试}

\subsection{静态代码验证}

在动态测试之前，团队采用了两类静态验证手段。

\textbf{TypeScript 类型检查}：前端 \texttt{build} 脚本将 \texttt{vue-tsc --noEmit} 配置为必要前置步骤，任何类型不兼容错误均会阻断构建流程。该检查覆盖全部页面组件、Pinia Store、API 接口封装与 \texttt{types/} 目录下的所有接口定义，确保前端数据结构与后端 API 契约的类型一致性。

\textbf{代码走查}：每个开发迭代完成后，团队成员对本迭代新增代码进行交叉走查（code walkthrough），重点核查认证与鉴权路径（\texttt{get\_current\_user} 依赖注入、资源归属校验）、多用户数据隔离边界与分类器异常分支的覆盖情况，走查意见在迭代内即时修正。

\section{发布状态}

系统已完成部署并进入可用状态。部署架构采用 Docker Compose + Nginx 方案，各组件配置如下：

\begin{itemize}
  \item \textbf{前端静态资源}：Vue 3 应用通过 Vite 构建为静态文件，由 Nginx 直接托管提供服务。
  \item \textbf{Nginx 反向代理}：监听 80 端口，前端路由由 Nginx 处理，\texttt{/api} 路径反向代理至后端 FastAPI 服务（\texttt{127.0.0.1:8000}）。
  \item \textbf{FastAPI 后端}：运行在内部 8000 端口，提供 RESTful API，由 Uvicorn 启动。
  \item \textbf{PostgreSQL}：持久化存储用户、交易、分类、组织、报表等业务数据。
  \item \textbf{Redis}：缓存与异步任务消息队列。低配部署时可通过 \texttt{TASK\_ALWAYS\_EAGER=true} 减少 Redis 依赖。
  \item \textbf{重试队列 Worker}：通过 FastAPI lifespan 事件启动后台线程，串行处理标记为 \texttt{retry\_queue} 状态的交易分类请求。
\end{itemize}

管理员账号通过后端 CLI 工具创建，不提供公开注册入口。生产环境配置包括环境变量注入（数据库连接、模型 API 密钥、Redis 地址等），通过 Docker Compose 的 \texttt{env\_file} 或裸机部署的环境变量文件管理。

系统当前版本已交付的完整功能包括：用户认证与数据隔离、微信/支付宝账单导入与解析、大模型语义分类与人工校正、Dashboard 财务分析、消费人格画像与财务健康评分、家庭组织管理与聚合分析、PDF 报表生成与下载、多供应商分类切换与重试队列容错。系统具备生产级部署能力，后端测试覆盖率达到 75\%，前端构建通过类型检查与生产构建验证。
